# Saavutettavuus

Tavoite on WCAG 2.2 AA, ei tässä toimituksessa varmennettu vaatimustenmukaisuus.

Toteutettu: semanttinen nav/main/header/footer, otsikot, näkyvät labelit, valikoiden aria-labelit, taulukoiden otsikot, progress-mittarit, näkyvä focus, sisältöön siirtymislinkki, native dialogin fokusraja, fokuspalautus, Escape, Ctrl/Cmd K, ilmoitusten status/alert, reduced-motion-sääntö ja raportin taulukkovastine.

Testattu: Ctrl K ja Escape selaimessa, budjetin tallennus Tabilla, lomakkeiden ja navigoinnin käyttö Playwrightin rooli/label-valitsimilla. Kaikkia käyttäjäpolkuja ei ole suoritettu pelkästään näppäimistöllä. Ruudunlukijaa, 200/400 % zoomia, kontrastimittauksia, axe-auditointia tai Windows High Contrast -tilaa ei ole kattavasti testattu.

Oman korostusvärin kontrastia ei lasketa automaattisesti; UI näyttää varoituksen. Summien piilotus ei peitä kaikkia johdettuja tietoja tai muokkauslomakkeita. Neljä valmista teemaa ja tumma tila ovat toteutettuja, mutta AA-kontrastia ei väitetä sertifioiduksi.
