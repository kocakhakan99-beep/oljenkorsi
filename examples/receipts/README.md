# Fiktiiviset testikuitit

14 satunnaistettua PDF-kuittia, kaksi kullekin parserin tunnistamalle kauppanimelle. Kaikki ovat merkittyjä testitositteita, eivät oikeita ostoksia.

Tuotteet, määrät, tarjoukset ja päivät arvotaan; jokaisen generointisiemen säilyy manifestissa. Summat lasketaan tuotteista, ei täytetä keinotekoisella tasauserällä. Painotuotteet, pantit, kassit, alennukset, tarjousryhmät, maksutapa ja ALV-erittely ovat mukana.

Prisman, S-marketin, Alepan ja K-Citymarketin rakenne perustuu varmennettuihin esimerkkimuotoihin. Salen, K-marketin ja K-supermarketin fiktiiviset kuitit käyttävät yhteisen S/K-sovittimen rakennetta; ne eivät vahvista näiden aitoja formaatteja.

Käyttö: Tuonti ja vienti → Kuittiskannaus → valitse PDF. Kategoriat ovat ehdotuksia ja epäselvät tuotteet luokitellaan käsin.
